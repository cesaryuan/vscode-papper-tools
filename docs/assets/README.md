# README artwork

`papper-tools-workflow.png` is an AI-generated conceptual illustration for the English and Chinese README. It is not a screenshot of the extension or a sample of its rendered Word output.

Generated with the `codex-image` CLI and `gpt-image-2`. The original delivery was 2172 × 724 pixels; the README asset is resized proportionally to 1800 × 600 pixels and stripped of image metadata.

Generation prompt:

> Create a wide conceptual editorial illustration for the GitHub README of Papper Tools, a VS Code companion for academic Markdown writing. Ivory background, navy and muted teal, restrained shadows and generous whitespace. Brand title exactly Papper Tools. Three simple object groups with only the short labels References, Styles, Preview. References: a Markdown paper card showing the short tokens @fig:results and @eq:loss connected by a curved navigation arrow. Styles: a small typography specimen Aa, subtle adjustment controls and a bibliography book. Preview: an academic page with gray text rules, an unlabelled tiny line chart and a small mathematical equation. This is an abstract workflow illustration, not a screenshot. Do not draw a detailed settings dialog, fake VS Code interface, journal dropdown, chatbot, invented metrics, export format claims, subtitle, slogan, app logo or watermark. Crisp readable English labels, balanced front-facing layout, approximately 3:1 composition.

The README links to Papper's actual Word examples separately. Those examples use `mathtype: true` and `mathtypeConversionMethod: mathtype`; this artwork does not claim to reproduce their typography or editor interface.
