# 将行布局扩展为可嵌套的面板布局

论文组合图需要表达左侧一张、右侧上下两张，以及进一步嵌套的组合。独立增加 Panel columns 只能覆盖另一种单层排列，用户还要切换模式，后续混合布局仍会受限。

采用一个面板布局模式，容器可以沿水平或垂直方向继续拆分，叶节点始终是一整张子图及其题注。拖到图片四边进行局部拆分，拖到整图外沿或周围 A4 纸张留白新增整行或整列，包含远离组合图的纸张底部；灰色虚线分隔线可以调整比例并显示吸附辅助线。行、列及常见不对称布局以预设提供，不增加互斥的编辑模式。

SVG 在原有编辑信息中保存嵌套结构和手动比例，普通可显示内容仍为图片与文字。旧行布局在打开时保持原几何，首次进行嵌套停靠时转换结构；自由定位继续保留。修改高级行数量或宽度比例会重建为行布局，修改间距和边距保留结构。

每张素材保留原始长宽比。默认按图片、固定字号题注和间距计算区域；无法恰好铺满时保留空白，用户通过独立的可逆裁剪操作调整可见部分。裁剪预览期间暂停布局重排，完成后一次性应用，以免拖动裁剪框时其他面板不断移动。
