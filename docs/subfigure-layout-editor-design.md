# 论文组合图布局编辑器设计

本文记录已经确认的范围、行为及首版实现，作为维护和后续扩展的依据。

## 已确认

- 在 Papper Tools 扩展中实现，底层格式为 SVG，暂不涉及 `papper convert`。
- 只编辑论文组合图的结构化布局，不支持编辑普通 SVG 的内部绘图元素。
- 默认采用按行组织的面板停靠布局：左右插入同一行，上下新建行，拖动时预览完整落位，通过行内分隔线调整相邻宽度；自由定位保留为独立模式。
- SVG 同时保存可显示的图形和继续编辑所需的布局信息，不另设布局源文件；参见 [保存格式决策](adr/0001-editable-subfigure-svg.md)。
- 子图素材默认以相对于组合图 SVG 的路径链接，支持切换为内嵌素材，以便独立交付 SVG。
- 第一版支持常见位图（如 PNG、JPEG、WebP）和 SVG 子图素材，SVG 作为完整子图导入；EMF、WMF、PDF 导入不在首版范围。
- 在编辑器中改变成图物理宽度时，保留子图相对位置和大小比例；标签和子题注保持设定的 pt 字号，子题注重新换行。自动排列由用户主动触发，不因改宽度覆盖手动微调。
- 第一版支持子图标签（如 `(a)`、`(b)`）、子题注和共享文字的独立文本框；总图题注由 Markdown 管理，不绘制进 SVG。
- 子图默认保持长宽比、完整显示，统一区域允许留白；可单独进入裁剪模式调整可见区域，原素材保持不变。
- 第一版只支持整张组合图的 Markdown 交叉引用，子图字母作为图内视觉标注；正文需要时在整图引用后手写字母，不增加 Papper 子图引用语法。
- 标签跟随子图，不因手动拖动位置而自动改变；提供按当前视觉顺序重编号的主动操作，并允许自定义标签。
- 创建入口包括命令新建、资源管理器多选素材、Markdown 创建与插入，以及将已有 `pandoc-crossref` 子图组转换为组合图 SVG 并进入编辑器。
- 从 Markdown 子图组导入后先进入编辑器；首次成功保存 SVG 时再替换原图组，沿用主图标识和总题注。放弃编辑不改变原稿。
- 转换已有图组时，将当前稿件内的独立子图引用同步改为主图引用加对应字母；遇到无法可靠改写的引用时，说明原因并停止替换，不产生失效的引用目标。
- 自动排列支持规则网格和逐行布局，逐行可指定不同子图数量和宽度比例。默认宽度按裁剪后的图片长宽比分配，让同一行图片等高；左右停靠会按等高重新分配目标行，其他行保持原宽度比例；上下停靠创建新行。显式设置或手动调整的比例仍保留。暂不维护跨行跨列的嵌套拆分树，复杂跨行布局通过自由定位完成。
- 文字采用基础富文本，支持字体、字号、颜色、粗体、斜体、上下标、换行和对齐；首版不解析 Markdown 或 LaTeX。
- 输出包括可继续编辑的 SVG 和按 DPI 导出的 PNG；首版不提供 PDF 导出。
- 编辑视图提供可切换的 A4 纸张参照（210 × 297mm），显示成图物理宽度及其占 A4 页宽的百分比；参照不进入导出的 SVG 或 PNG。

## 整体审阅时采用的默认方案

以下为整体审阅后采用的首版默认行为。

### 编辑界面与交互

- 界面由顶部操作栏、左侧元素列表、中间画布和右侧属性面板组成，沿用扩展的中英文界面机制。
- 支持多选、拖放添加素材、移动、调整大小、复制、删除、键盘微调、对齐、吸附和等间距分布。
- 支持撤销重做、标准保存快捷键及未保存状态，保存和恢复遵循 VS Code 编辑器习惯。
- 工具栏撤销重做与原生快捷键共享历史，按钮根据可用历史置灰；全部按钮提供中英文悬浮说明。
- 以左侧可视拖拽和布局预设为主入口，右侧高级网格设置保留默认每行数量、自定义逐行数量、宽度比例和间距；自定义数量覆盖默认数量。
- 拖动在松手时产生一次撤销记录，Escape 取消停靠；预览不写入 SVG。分隔线只改变相邻子图宽度的分配，不改变整图尺寸和文字物理字号。
- 行间宽度分隔线使用灰色虚线。按行布局自动更新，Auto arrange 按钮置灰；自由定位中可用它按网格重排。
- 分隔线吸附到画布宽度的 1/4、1/3、1/2、2/3、3/4、相邻子图等宽或裁剪后图片等高的位置，以及其他行的分隔线。吸附半径为屏幕 6px，脱离距离为 9px，避免边缘抖动；吸附目标须满足相邻子图最小宽度。临时辅助线标明吸附位置，松手后不保留；遵循吸附复选框，Alt 临时跳过。
- 自由移动按整个选区的边缘和中心吸附到画布或其他元素的边缘和中心，横纵轴分别处理，显示对应的水平、垂直辅助线及目标说明。多选保持内部相对位置，吸附距离与分隔线一致；辅助线只属于编辑界面，不写入 SVG 或 PNG。
- 拖动按浏览器帧合并事件，自由移动通过已有元素的位移预览更新，避免重复重建图片；Panel 拖动持续显示跟随指针的半透明副本，停靠目标改变时才更新布局预览，调整尺寸时保留已有图片节点。松手时提交最新指针位置，取消时恢复原布局。
- 左侧元素列表决定自动排列顺序，可拖到画布中停靠；按行停靠同步更新保存的行数和子图顺序，自由定位中的移动不改变列表顺序。标签跟随图片，保持主动重编号。
- 标签和子题注默认放在图片下方，可调整其位置与间距。移动图片时附属文字随子图移动，共享文字独立移动。
- 只将具有组合图结构信息的 SVG 作为布局文档打开，普通 SVG 沿用现有预览和源码查看入口，也可以作为子图素材导入。

### 尺寸、文字与画布

- 初始成图宽度为 160mm，可修改并切换 mm/in 显示；文字以 pt 设置，默认 Times New Roman、10pt。中文文字使用可选中文字体。
- 内部排版使用物理尺寸，SVG 的物理尺寸、坐标映射和 Markdown 插图宽度保持一致，避免生成后再通过任意百分比缩放改变字号。
- 默认白色背景，可切换透明；画布高度随布局内容调整，也可手动设置。
- 更改宽度时保持已有子图相对位置和大小比例，附属文字保持字号并重新换行，不自动覆盖手动布局。
- 原子图素材内部的字形、图例和坐标轴作为图片内容保留，不承诺与新增文字字号统一。
- 在 Word 中进一步整体缩放 SVG 会同时缩放图内文字；固定字号规则针对编辑器中的布局调整。A4 参照不代表目标稿件的实际页边距或栏宽。

### SVG 保存与素材更新

- 可显示图形与版本化的编辑信息一起保存到 SVG 中，不依赖独立布局源文件。
- 默认素材链接相对于组合图 SVG；另存到其他目录时重新计算链接，内嵌模式下不依赖外部素材文件。
- 相对链接指向的素材更新后刷新显示，保留已有布局、标签和裁剪区域。
- 裁剪只改变组合图中的可见区域；SVG 和 PNG 导出使用相同布局、字体和裁剪结果。
- 不在导出时压缩或缩小原素材；PNG 分辨率按物理尺寸和所选 DPI 计算。

### Markdown 图组转换

- 首版导入常见 `::: {#fig:...}` 和 `<div id="fig:...">` 图组，恢复子图顺序、图片分行、百分比宽度、标签、子题注、总题注及已有裁剪属性。
- 可直接复用基础富文本支持的题注格式；超出首版转换范围的内容说明原因并保留原图组，避免丢失内容。
- 主图标识与总题注随 SVG 普通图片引用保留；不将总题注绘制进 SVG。
- 首次保存前记录原图组范围与内容；保存时若稿件已被修改，重新核对目标后再执行替换。
- 首次保存操作将 SVG 创建、图组替换和当前稿件内的子图引用改写作为一个完整用户操作处理，保留清晰的撤销路径。
- 图组替换使用稿件当前编辑缓冲区，不要求先保存其他无关修改。

## 实现前已核实的仓库情况

- 现有 SVG 自定义编辑器负责预览，不提供布局编辑。
- 已有图片目录预览、本地 SVG 子图片解析、Webview 资源处理和界面本地化，可以复用相关边界能力。
- 当前 Markdown 扫描器已有 fenced Div 范围和 HTML Div 图组标识信息，但还需要实现图组图片、题注和引用的完整转换模型。
- SVG 子图片在 Papper DOCX 构建中的兼容处理需通过真实组合图核验；SVG 保存正确与最终 DOCX 保留矢量需要分别验证。

## 验证重点

- 保存并重新打开后，布局、富文本、素材链接和裁剪保持一致。
- 调整成图宽度后，新增文字维持设定物理字号；PNG 的尺寸符合指定 DPI。
- 自动排列保留全部子图，手动微调、标签跟随和主动重编号行为一致。
- 图组转换保留总题注、格式、主图标识和各子图，子图引用改写后仍可用于稿件构建。
- 放弃转换编辑、保存失败、原稿同步修改和撤销不会造成稿件内容丢失。
- 以真实位图、SVG 和混合素材组合图检查 SVG、PNG 及 Papper DOCX 的可见结果。
- 自动测试聚焦以上稳定且可独立断言的行为，交互和最终显示用实际编辑器及导出文件验证，不新增仅断言配置或代码接线的测试。
